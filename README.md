### 🤖 AI-Powered RFP Discovery Platform

An intelligent procurement discovery platform that automates the
process of finding and ranking relevant tender and procurement
opportunities.

**What I built:**

- Developed a web-scraping pipeline to continuously ingest tender and
  procurement documents from public portals
- Parsed and extracted structured information from RFP PDFs
- Built an NLP-based information retrieval system
- Used **TF-IDF and semantic similarity** to match RFPs against company
  capability profiles
- Ranked procurement opportunities based on relevance
- Automated a discovery process that traditionally required manual
  review

**Tech Stack:**

`Python` `NLP` `TF-IDF` `Semantic Similarity` `Web Scraping`
`PDF Processing` `Information Retrieval`

### 🛣️ SafeStreet — Road Damage Detection

A full-stack road monitoring platform for real-time reporting and
detection of road damage.

**What I built:**

- Architected a MERN-stack platform using React Native, React.js,
  Node.js, Express.js and MongoDB Atlas
- Designed REST APIs for real-time road-damage reporting
- Implemented GPS-tagged field data collection
- Built a supervisor analytics dashboard
- Integrated a **Vision Transformer (ViT)** through Hugging Face
- Implemented multi-class classification for:
  - 🕳️ Potholes
  - 🧱 Cracks
  - 💧 Waterlogging
- Added confidence scoring to model predictions
- Deployed frontend and backend using Vercel and Render
- Implemented automated PDF report generation and email notifications

**Tech Stack:**

`React Native` `React.js` `Node.js` `Express.js` `MongoDB Atlas`
`REST APIs` `Vision Transformer` `Hugging Face` `Vercel` `Render`

### 📈 Entity Pulse — Financial Sentiment Analysis

An NLP system designed to perform fine-grained sentiment analysis
on financial text at the entity level.

**What I built:**

- Developed a transformer-based NLP pipeline using **FinBERT**
- Integrated **Named Entity Recognition (NER)** to identify companies
  and financial entities
- Performed entity-level sentiment classification rather than
  document-level sentiment analysis
- Generated probability-based sentiment outputs
- Worked with financial news and market-related text
- Designed the system to provide more interpretable sentiment insights
  for financial analysis

**Tech Stack:**

`Python` `FinBERT` `NER` `NLP` `PyTorch`
`Hugging Face Transformers` `Pandas` `NumPy`
